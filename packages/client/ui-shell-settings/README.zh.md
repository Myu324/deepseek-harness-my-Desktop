# @deepseek-ai/dsh-client-ui-shell-settings

[English](README.md) | 中文

Web GUI 的桌面客户端设置分区。浏览器半区注册一个 `settings.section`（id `shell`，位于通用与模型分区之后），渲染引擎状态与重启、开机自启、客户端界面语言、壳/引擎更新检查、插件市场与退出——每个动作都是桌面客户端主窗口 `window.shell` 预载桥上的普通回调。该分区只在桥存在时注册，因此普通浏览器会话永远不会看到桌面专属界面；回调触发的所有引擎侧行为都由 Electron 主进程负责。

## 模型体验

无。该设置分区是桌面壳桥上的浏览器侧展示界面；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **打包引擎必须先发布本包**：npm 发布的 `dsh` web-app 包早于本包，因此「桌面客户端」分区要等到包含本包的发布之后才会出现在打包客户端中；开发仓库引擎在重建 Web 后即可见。
